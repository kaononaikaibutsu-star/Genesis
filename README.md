# Project Genesis

A cross-platform desktop application built with **Electron** and modern web technologies.

---

## 🚀 Features

- **Cross-Platform**: Designed to run seamlessly across Windows, macOS, and Linux.
- **Fast & Responsive**: Optimized for smooth performance and minimal resource usage.
- **Modern UI**: Clean, responsive interface built for personal task and app management.

---

## 🛠️ Built With

* [Electron](https://www.electronjs.org/) - Desktop application framework
* [JavaScript / HTML / CSS] - Frontend interface

---
